# Roboto

Archivos WOFF2 locales, normal y cursiva, con pesos variables de 100 a 900. Se generaron mediante compresión de formato con FontTools a partir de los archivos oficiales de Google Fonts. No se modificaron los diseños de los caracteres.

Fuentes:
- https://github.com/google/fonts/tree/main/ofl/roboto
- Roboto[wdth,wght].ttf
- Roboto-Italic[wdth,wght].ttf

La licencia SIL Open Font License se conserva en OFL-Roboto.txt. No se necesita conexión con Google Fonts para cargar las fuentes en el recorrido.
