# Recursos para pensar un posible diseño

La participación compartida del módulo se realiza en el foro del aula, según la consigna del equipo. Las notas y herramientas del recorrido son de uso personal. La plantilla no constituye otra entrega ni hay corrección automática de las explicaciones.

## Guía comentada

[De una intuición a una decisión de diseño](GUIA_COMENTADA.md) comenta un ejemplo hipotético para aprender a argumentar con fuentes mediante una mesa de edición. Recorre propósito, relación metafórica, decisión concreta y fundamento provisional con límites y posibles observaciones. Está disponible como lectura opcional en el tramo final del módulo, sin nuevos campos de respuesta.

## Plantilla opcional

- [PDF rellenable](../../descargas/Kit_del_caso_a_tu_objeto_rellenable.pdf)
- [PDF para imprimir](../../descargas/Kit_del_caso_a_tu_objeto.pdf)
- [Word editable](../../descargas/Kit_del_caso_a_tu_objeto.docx)
- [Contenido](CONTENIDO.md)

La plantilla se conserva como herramienta opcional para explorar una idea, preparar el aporte al foro o retomar un futuro diseño. Permite pensar un posible objeto sin suponer que ya se está desarrollando. Mantiene tres páginas y doce campos en blanco; la segunda página ofrece alternativas equivalentes, probar una metáfora o elegir otra organización. El cierre invita a volver sobre la decisión.

El PDF imprimible conserva texto seleccionable y Roboto incrustada. El rellenable agrega doce campos multilínea y usa Helvetica para las respuestas. El DOCX permite editar textos y espacios; su paginación depende del editor y las fuentes instaladas. No se afirma una auditoría completa de accesibilidad.

Para completar el PDF, descargarlo y abrirlo en un lector compatible con formularios; guardar una copia propia. No envía información al foro. Los archivos distribuidos están vacíos.

Para regenerar los campos a partir del PDF imprimible: `python documentacion/kit-metafora/generar_rellenable.py`, con PyMuPDF instalado.
