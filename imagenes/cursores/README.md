Cursores del recorrido

Cuatro PNG transparentes de 40×40 px, renderizados en navegador a partir de los bocetos originales de C.inkArt: larva, crisálida, eclosión y mariposa. Un soporte claro mejora el contraste. Punto activo en 20,20. Se usan como cursores nativos CSS en dispositivos con mouse; los campos de texto mantienen cursor de escritura y los controles deshabilitados, su estado.
