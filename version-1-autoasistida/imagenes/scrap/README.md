# Piezas para la prueba scrap

`piezas-papel.png` es una lámina transparente generada para explorar el tratamiento aprobado en la lámina conceptual. Se usa en el índice principal y en `propuesta-scrap.html`, mediante fondos CSS y ventanas de recorte. No reemplaza los bocetos originales del módulo.

La grilla 3 × 3 contiene: fondo de carpeta, solapa, hoja; mesa de observación, lente, cuerpo de caja; tapa, tiras, cuatro recortes. Los elementos se montan en capas distintas para animar su posición y apertura. Los textos y dibujos originales se mantienen como elementos separados.


`escenas-educativas.png`: hoja de seis escenas generada a partir del boceto aprobado; se muestran las tres superiores mediante CSS, sin alterar el PNG. `podcast-1.svg` a `podcast-4.svg` y `artefacto-1.svg` a `artefacto-4.svg`: originales aportados por el equipo, conservados sin modificaciones, usados en la síntesis de caminos.
